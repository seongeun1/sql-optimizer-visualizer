# SQL Optimizer Visualizer

📖 Restarting my coding journey

## Visualize the SQL Execution 
using 'EXPLAIN (FORMAT JSON)'


### Tech Stack
> - Python3
> - PostgreSQL
> - psycopg2
> - JSON output format from 'EXPLAIN'

### Features
> - Connect to local PostgreSQL
> - Accepts SQL input from the user
> - Parses 'EXPLAIN' JSON output
> - Prints query execution plan as a readable tree

### Setup
> pip install -r requirements.txt
> python visualizer.py
